# 未來整包：全臺鄉鎮天氣預報（F-D0047-093）

整理日期：2026-11-12。本文所有時間皆為臺灣時間（Asia/Taipei）。

本文件記錄氣象署實際整包有哪些資料、時間間隔、有效範圍與數值例子。這些是未來預報，不是已發生的 GT 現況。我們預計用哪些項目、多久取得、怎麼保存，集中記錄於 [預計使用資料與紀錄方式.md](../預計使用資料與紀錄方式.md)。

## 來源、授權與本次核對

- 資料集：**全臺灣各鄉鎮市區預報整包（官方資料集代號：F-D0047-093）**。這串代號用來指定要下載哪一份資料，不是天氣狀況或預報數值。
- 取得方式：官方檔案下載介面（fileAPI），下載的是壓縮檔（ZIP），內含結構化資料檔（XML）。
- **需要中央氣象署 API 授權碼（API key）**。本文不保存授權碼或帶授權碼的網址；本機設定與保管方式另見資料規劃文件。
- 本次核對日期：**2026-11-12**；數值例子於 **16:07** 再次下載確認。
- 本版檔內的**預報發布時間（`IssueTime`）**：**2026-11-12 11:00**；各檔的**資料更新時間（`Update`）**約為同日 **12:15～12:16**。這兩個欄位代表不同的時間。
- 整包共 **141 個檔案**：**138 個 XML＋3 個 CSV**。138 個 XML 均可解析。
- 鄉鎮資料包含 **22 縣市、368 鄉鎮**；另有以 22 縣市為地點的全臺彙總產品，以及中英文版本。

## 三組預報檔案

以臺北市中文檔為例，其他縣市亦有對應檔案。

| 檔案意思（原始檔名） | 用途 | 本版實際涵蓋時間 |
| --- | --- | --- |
| 臺北市短期預報・中文（`63_72hr_CH.xml`） | 短期細時段預報，10 類氣象因子 | 11/12 12:00～11/16 12:00；點資料最後一筆為 11/16 09:00 |
| 臺北市日夜預報・中文（`63_Weekday_CH.xml`） | 日夜／逐 12 小時預報，15 類氣象因子 | 11/12 12:00～11/19 06:00 |
| 臺北市逐日預報・中文（`63_Week24_CH.xml`） | 逐日預報，15 類氣象因子 | 11/12 12:00～11/19 00:00 |

這些檔名中的 `63` 代表臺北市，`CH` 代表中文，對應的 `EN` 代表英文；`TAIWAN` 開頭則代表全臺縣市彙總產品。`72hr` 是短期產品的檔名標記，不保證每版都只有 72 小時；`Weekday` 在這份整包代表日夜預報，`Week24` 代表逐日預報。

另有三個表格格式檔案（CSV）：**檔名與用途清單（`file.csv`）**、**檔案與格式說明對照表（`manifest.csv`）**、**清單欄位說明（`schema-file.csv`）**。應以資料內的時間判斷有效範圍。

## 短期：有什麼與實際間隔

| 資料 | 本版實際時間間隔 | 本版有效範圍 |
| --- | --- | --- |
| 氣溫、體感、相對濕度、露點、舒適度及描述 | 先逐 **1 小時**，再逐 **3 小時** | 11/12 12:00～11/14 00:00 為逐小時，共 36 小時；之後逐 3 小時，最後一筆為 11/16 09:00。每項共 56 筆點資料／鄉鎮 |
| 風向、風速、蒲福風級 | 逐 **3 小時** | 11/12 12:00～11/16 09:00，共 32 筆點資料／鄉鎮 |
| 3 小時降雨機率、天氣現象與代碼、天氣預報綜合描述 | 每 **3 小時一個時段** | 11/12 12:00～11/16 12:00，共 32 個時段／鄉鎮 |

官方名義規格為「1 天內逐 1 小時、3 天內逐 3 小時」，但這次實際提供 **36 小時逐小時資料、4 天短期時段預報**。每一版都需重新依實際時間判斷，不能將本次長度視為永久保證。

點資料使用**預報時間點（`DataTime`）**；時段資料使用**預報開始時間（`StartTime`）**與**預報結束時間（`EndTime`）**。例如 12:00 的氣溫是該時間點預報，12:00～15:00 的降雨機率是整段預報，兩者意義不同。

## 日夜與逐日：有什麼與實際間隔

| 資料 | 日夜預報 | 逐日預報 |
| --- | --- | --- |
| 平均氣溫、平均露點、平均相對濕度 | 通常每 12 小時 | 通常每 24 小時 |
| 最高／最低氣溫 | 時段高低值 | 當段日預報高低值 |
| 最高／最低體感 | 時段高低值，沒有單一體感值 | 當段日預報高低值，沒有單一體感值 |
| 最大／最小舒適度及描述 | 時段最大／最小 | 當段日預報最大／最小 |
| 風向、風速、蒲福風級 | 每 12 小時；官方規格將較長時段風速列為最大風速 | 每日；官方規格將較長時段風速列為最大風速 |
| 天氣現象、天氣代碼、綜合描述 | 每 12 小時 | 每日 |
| 紫外線指數、曝曬級數 | **每天白天一筆，夜間沒有此筆資料** | 每日一筆 |
| 降雨機率 | 12 小時機率，只有較近時段有有效值 | 24 小時機率，只有較近日期有有效值 |

本版的時間安排：

- **日夜預報**：通常為 06:00～18:00、18:00～隔日 06:00；本版首段是 **11/12 12:00～18:00，只有 6 小時**。一般項目每鄉鎮 14 個時段。
- **逐日預報**：通常為 00:00～隔日 00:00；本版首段是 **11/12 12:00～11/13 00:00，只有 12 小時**，之後才是完整日。每鄉鎮共 7 個時段。
- **日夜紫外線**：本版共 7 筆，首段為 11/12 12:00～18:00；之後每日 06:00～18:00，最後為 11/18 白天。夜間沒有資料不代表官方給了數值 0。
- 今天首筆逐日高低值只涵蓋剩餘時段，**不能當成今天全天的預報高低值**。也不能直接合併跨日的白天、晚上當作同一日曆日。

## 降雨機率：三種產品的有效範圍不同

本次 368 鄉鎮的時間安排一致：

| 產品 | 本版有效時間 | 每鄉鎮有效筆數 | 後續資料 |
| --- | --- | --- | --- |
| 3 小時降雨機率 | 11/12 12:00～**11/16 12:00** | 32 個時段 | 本版短期產品內皆有值 |
| 12 小時降雨機率 | 11/12 12:00～**11/15 06:00** | 6 個時段，首段不足 12 小時 | 剩下 8 段以 `-` 表示缺值 |
| 24 小時降雨機率 | 11/12 12:00～**11/15 00:00** | 3 個時段，首段不足 24 小時 | 剩下 4 段以 `-` 表示缺值 |

因此不能統一說所有降雨機率都只有 3 天，也不能把 3 小時機率直接當成 12／24 小時機率。缺值保留空白，三種時段長度分開保存與顯示。

## 本文數字與符號的白話意思

| 原始數字或符號 | 代表意思 |
| --- | --- |
| 天氣代碼 `04` | 多雲 |
| 天氣代碼 `03` | 多雲時晴 |
| 蒲福風級 `2` | 輕風，對應風速每秒 1.6～3.3 公尺 |
| 風級範圍 `<= 1` | 1 級以下，包含無風（0 級）或軟風（1 級） |
| 風級範圍 `>= 6` | 6 級以上，強風或更強的風；不是確定只有 6 級 |
| 紫外線指數 `4` | 中量級；官方分級中的 3～5 都屬中量級 |
| 舒適度指數 `26` | 本次資料同時附的官方文字描述為「舒適」；26 是指數值，不是天氣代碼 |
| 降雨機率中的 `-` | 沒有提供有效數值，不代表降雨機率 0% |
| 風速單位 `m/s` | 每秒公尺，例如 `2 m/s` 是每秒 2 公尺 |

天氣代碼是分類，同一代碼可能有不同的中文描述；閱讀時以同筆資料附的**天氣中文描述**為準。舒適度也附有官方文字描述，本文保留原本提供的文字。

風級意思依據 [氣象署資料標準的蒲福風級表](https://opendata.cwa.gov.tw/opendatadoc/insrtuction/CWA_Data_Standard.pdf)；紫外線級數依據 [氣象署紫外線指數預報服務說明](https://www.cwa.gov.tw/Data/knowledge/announce/service13.pdf)；天氣代碼可參考 [官方天氣描述代碼表](https://opendata.cwa.gov.tw/opendatadoc/MFC/D0047.pdf)，本文的代碼與中文亦已核對同筆整包資料。

## 官方發布時間

- 官方通常每日 **05:30、11:30、17:30、23:30** 發布，必要時另行更新。這是發布頻率，不是預報時段間隔。
- 本版檔內的預報發布時間（`IssueTime`）、資料更新時間（`Update`）與上述時刻不同，不能直接視為相同時間；實際值見本次核對紀錄。
- 整包與查詢 API 是否同時上線，仍待持續追蹤。

## 本次沒有的資料與核對限制

- 整包沒有未來降雨量 **mm**、日出、日落欄位；降雨機率不是雨量。
- 短期沒有獨立的最高／最低氣溫與體感欄位；日夜及逐日產品則沒有單一體感欄位。
- 本次逐項檢查了 22 縣市中文鄉鎮檔，共 368 鄉鎮；時間安排一致。除較遠的 12／24 小時降雨機率以 `-` 缺值外，其餘列出欄位都有值。
- 英文及全臺彙總 XML 已確認可解析，但未逐項比對與中文鄉鎮數值的一致性。
- 以上是單一版本的快照，不保證每次發布都有相同長度、值或完整程度。
