## 已確認的體驗目標

- 現代簡約，容易閱讀，文字盡可能少。
- 操作簡單，可以從小時到一週連續縮放。
- 三種數值的時間範圍同步，能查看過去與未來。
- 使用動畫讓過渡流暢。

上述是使用者要求。下列布局、色碼、圖示與操作細節是第一版實作方案，仍可依使用者回饋調整。

## 時間軸規則

- 首次顯示：台灣時間今天 00:00–24:00。
- 單次可見範圍：最小 1 小時，最大 7 天，可連續縮放。
- 可平移的總範圍：以參考「現在」為界，過去 7 天至未來 7 天。
- 「3 天」：從參考現在開始，往後 72 小時。
- 「一週」：從參考現在開始，往後 168 小時。
- 「過去一週」：從參考現在往前 168 小時。
- 「現在」：保持目前縮放尺度，將參考現在移到視窗中心；遇邊界會限制範圍。
- 「今天」：回到當天 00:00–24:00，而不是保持原縮放尺度。

上述精確定義是目前程式行為。使用者已確認連續縮放與前後一週，尚未確認首頁置中方式及最小 1 小時設定。

目前參考時間在開頁時設定，讀取官方資料時再更新；長時間開頁或跨日的行為列為待驗證項目。

## 操作方式

| 使用情境 | 已寫入程式的操作 |
| --- | --- |
| 電腦 | 圖表滾輪縮放、左右拖曳平移、雙擊放大。 |
| 觸控板 | 主要垂直捲動量用於縮放，主要水平捲動量用於平移。 |
| 手機 | 單指水平拖曳，雙指縮放。 |
| 共用控制 | 時段按鈕、縮放滑桿、加減按鈕、總覽選取框。 |
| 總覽 | 拖曳選取框平移；拖曳左右兩端調整範圍；點擊空白區跳轉。 |
| 數值閱讀 | 滑鼠移到圖上或點按圖表，顯示資料點的時間與數值。 |
| 曲線顯示 | 點按溫度／體感圖例切換顯示，保留至少一條溫度曲線；濕度固定顯示。 |
| 鍵盤 | 圖表取得焦點後，用左右鍵平移、加減鍵縮放、Home 回到現在；總覽兩端也有方向鍵處理。 |

「已寫入程式」不代表所有裝置手勢都已完整實測。手機瀏覽器實機、觸控板及長時間操作的驗證仍在待辦。

## 動畫方案

- 快速定位與按鈕縮放採約 280 毫秒的時間插值動畫。
- 直接拖曳、滑桿與雙指操作即時更新，跟隨操作位置。
- 曲線的垂直刻度有漸變處理。
- 輔以圖表淡入、對話框與提示的短過渡。
- 遵循裝置的「減少動態效果」設定。
- 已調整動畫計時，避免背景分頁節流後持續停在中間範圍；長時間背景／前景切換仍需完整驗證。

## 待確認與待驗證

產品決定見 [Q01–Q07](06-後續工作.md)。操作方面優先驗證：

1. 手機圖表縮放與頁面上下捲動是否互相干擾。
2. 最小字級與淡色曲線是否容易閱讀。
3. 1 小時與 7 天兩個極端尺度，是否仍能清楚理解時間與數值。
4. 陰影範圍和中線是否讓使用者誤解成精確逐時預報。
5. 資料設定與最小必要說明是否符合「少文字」的期待。
