# 資料規劃維護方式

更新日期：2026-11-13（Asia/Taipei）

這個資料夾把官方資料說明、欄位選擇工具與使用規劃放在一起。日常只要記住兩件事：**官方資料改共用目錄；想顯示什麼、備註寫什麼，在網頁修改並儲存。**

目前使用已核對的資料快照，還沒有自動抓取最新氣象資料或持續收集過去紀錄。更新文件不等於更新即時天氣。

## 檔案放在哪裡

```text
資料規劃/
├─ 維護方式.md
├─ 預計使用資料與紀錄方式.md
├─ 中央氣象署/
│  ├─ 資料目錄.json
│  ├─ shared_catalog.py
│  ├─ 鄉鎮市GT.md
│  ├─ 未來整包.md
│  └─ 官方意思核對紀錄.md
└─ 欄位選擇/
   ├─ server.py
   ├─ public/                  網頁檔案
   ├─ 選擇結果.json
   ├─ initial-selection.json
   ├─ 畫面資料規劃.md
   └─ test_shared_catalog.py
```

| 想改什麼 | 修改位置 | 怎麼維護 |
| --- | --- | --- |
| 官方欄位、原始值、代碼意思、時間範圍與更新方式 | [資料目錄.json](./中央氣象署/資料目錄.json) | 這是唯一的共用資料來源，網頁與來源文件都讀它 |
| 三個區塊的勾選、整體／區塊／逐項備註 | [選擇網頁](http://127.0.0.1:8766/) | 按「儲存」後寫入 [選擇結果.json](./欄位選擇/選擇結果.json) |
| 資料多久取得一次、怎麼保存與補漏的規劃 | [預計使用資料與紀錄方式.md](./預計使用資料與紀錄方式.md) | 手動維護，決定改變時同步調整共用目錄中的對應取得規劃 |
| 網頁功能與樣式 | [public](./欄位選擇/public/) | 修改網頁程式；重新整理後核對原有選擇仍在 |
| 啟動、讀寫與文件產出功能 | [server.py](./欄位選擇/server.py)、[shared_catalog.py](./中央氣象署/shared_catalog.py) | 修改後重啟服務並執行檢查 |
| GT、未來整包、核對紀錄與畫面資料規劃等 MD | 下方列出的四份產出文件 | **由程式產生，不直接手改**，避免下次同步被覆蓋 |

`initial-selection.json` 只是找不到選擇結果檔時的初始值，不是目前使用者的選擇。正常維護不靠改它來重設勾選。

## 開啟選擇網頁

最方便的方式：雙擊專案根目錄的 [開啟欄位選擇.cmd](../開啟欄位選擇.cmd)。它會自動啟動服務並用預設瀏覽器開啟網頁；服務已開著時會沿用。新啟動服務的視窗要保持開啟，關閉視窗或按 `Ctrl+C` 就會停止服務。

也可以在專案根目錄，也就是 `README.md` 所在的「天氣」資料夾，執行：

```powershell
python "資料規劃/欄位選擇/server.py"
```

開啟 <http://127.0.0.1:8766/>。終端機保持開啟，結束服務時按 `Ctrl+C`。

固定使用這個網址。換成 `localhost`、另一個連接埠或另一個瀏覽器，未儲存的瀏覽器草稿不會自動跟過去；已儲存在專案的選擇仍可讀取。若連接埠已被使用，先確認是否已開著這個服務。

這次只搬專案檔案，網址與瀏覽器暫存識別名稱都維持原樣。

## 修改勾選與備註

1. 在網頁切換「現在狀態」「逐時預報」「一週預報」。
2. 勾選主畫面或詳細頁需要的項目，填寫整體、區塊或逐項備註。
3. 用「查看選擇」核對，再按「儲存」。

勾選與備註會存進 `欄位選擇/選擇結果.json`，同時產生／更新：

- [畫面資料規劃.md](./欄位選擇/畫面資料規劃.md)
- [鄉鎮市GT.md](./中央氣象署/鄉鎮市GT.md)
- [未來整包.md](./中央氣象署/未來整包.md)
- [官方意思核對紀錄.md](./中央氣象署/官方意思核對紀錄.md)

尚未按儲存時，修改只暫存在該瀏覽器。關鍵選擇請儲存後再備份；「下載已儲存的規劃」下載的是已寫入專案的版本。

## 查到新官方資料時

先修改 `中央氣象署/資料目錄.json`，不用把相同說明分別抄進網頁與 MD。

| 共用目錄的位置 | 要更新的內容 |
| --- | --- |
| `references` | 官方網址、文件版本、查閱位置與核對日期 |
| `sources` | 來源、官方發布頻率、我們預計多久檢查；這兩種頻率分開寫 |
| `fields` | 官方意思、補充說明、單位、原始樣本、間隔、相對範圍與核對狀態 |
| `lookups` | 天氣代碼、風級、舒適度、紫外線、缺值與鄉鎮代碼對照 |
| `verificationAudit` | 這次查到什麼、還缺什麼、依據與處理方式 |
| `snapshot`、來源的 `relativeAnchor` | 樣本取得時間、地點與各版預報的時間起點 |
| `sections` | 三個區塊可選的項目及其對應欄位；不是使用者已儲存的勾選 |

新樣本要保留官方原始值與實際起訖，再同步更新相對時間範圍。不能只把快照日期改成今天，或沿用舊版「前幾小時」的範圍當成新預報。

同一欄位的識別碼要保持穩定，不能只因改中文名稱就換代碼。移除或改掉已有勾選／備註的代碼，需要先處理對應關係；工具遇到不認得的既有代碼會拒絕儲存，不會自行丟掉備註。

官方文件有矛盾或找不到公開規格時，保留「待確認」、官方依據與暫時採用方式，不直接改成已確認。

## 同步資料說明與 MD

改好共用資料後，在網頁進入「備註與文件」，按「更新資料說明」。這會保留目前勾選與備註，並以專案**已儲存的選擇**重產文件；若網頁另有未儲存的變更，要再按「儲存」才會進入規劃 MD。

也可以在專案根目錄執行：

```powershell
python "資料規劃/中央氣象署/shared_catalog.py"
```

這個指令不會重寫 `選擇結果.json`。啟動服務也會同步產生文件；更新網頁上的資料說明後，核對畫面與文件版本是否相同。

若修改的是 Python 服務程式，先停止舊服務，再用新路徑重新啟動；修改網頁程式則重新整理網頁。

## 備份與還原

最簡單的備份方式，是儲存選擇後複製整個 `資料規劃` 資料夾。至少要保留：

- `欄位選擇/選擇結果.json`：你的勾選與全部備註。
- `中央氣象署/資料目錄.json`：與這些選擇相容的資料定義。
- `預計使用資料與紀錄方式.md`：手動維護的使用與保存決定。

四份產出的 MD 可以重新產生，不能只拿它們當作勾選與備註的完整備份。工具有寫入失敗時的回復處理，但不會替每次成功儲存自動保留歷史備份。

還原前先備份目前內容並停止服務，再還原對應版本的上述檔案，重新啟動產生文件。若網頁顯示「已還原未儲存的變更」，表示瀏覽器還有較新的草稿；先核對、保留草稿內容，再決定採用哪份，避免直接儲存蓋過剛還原的檔案。

專案根目錄的 `outputs/` 若存在，只存工作用備份、下載文件與截圖，不是正式資料來源，也不納入版本控制，可按需要清理。需要長期保留的備份，請另外存到自己指定的位置；正式勾選與備註仍以 `資料規劃/欄位選擇/選擇結果.json` 為準。

## 修改後怎麼檢查

在專案根目錄執行：

```powershell
python "資料規劃/欄位選擇/test_shared_catalog.py"
```

檢查包含勾選與備註保留、共用資料同步、代碼對照、時間範圍及寫入失敗回復。再開網頁確認三區資料、原始例子與備註正常，並確認按儲存／更新說明後，文件都產生在 `資料規劃` 裡。

專案根目錄的 `.env` 仍留在原處。API key 不寫進共用目錄、來源說明或備份範例；目前這個選擇工具讀本機快照，不需用 API key 連線才能開啟。
