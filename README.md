# 天氣 Web App

## 想做什麼

利用中央氣象署提供的資料，以今天為主，能即時顯示現在過去未來一週內。

## 裝置與方向

先著重手機，簡約少文字、操作流暢。目前先採全前端，其他螢幕共用手機布局，後續依使用感受調整。

## UI／UX

- 畫面現代簡約 操做簡單 文字盡可能少除非必要，甚至不使用文字；或用其他方式呈現 
- 畫面與狀態之間的過渡使用適度動畫，讓操做和回饋流暢自然。

## 目前進度

草稿階段，先製作前端預覽，思考怎麼呈現。
確認所需資料

## 資料規劃與來源

資料與選擇工具統一放在 [資料規劃](./資料規劃/)，操作與更新方式見 [維護方式](./資料規劃/維護方式.md)。

- [預計使用資料與紀錄方式](./資料規劃/預計使用資料與紀錄方式.md)：我們預計用哪些資料、多久取得一次、怎麼保存與補漏。
- [中央氣象署：鄉鎮市 GT](./資料規劃/中央氣象署/鄉鎮市GT.md)：現在與過去可取得的資料、欄位及實際例子。
- [中央氣象署：未來整包](./資料規劃/中央氣象署/未來整包.md)：未來預報的資料種類、時間間隔及實際例子。
- [官方意思核對紀錄](./資料規劃/中央氣象署/官方意思核對紀錄.md)：代碼與欄位已查明的意思、仍有矛盾的規格、官方依據及 368 鄉鎮代碼對照；由共用目錄產生。

## 欄位選擇與共用資料

- [共用資料目錄](./資料規劃/中央氣象署/資料目錄.json)：原始值、官方意思、依據、核對狀態、時間間隔、官方更新與我們預計的取得頻率。三區選項引用同一份資料。
- 啟動選擇頁：雙擊 [開啟欄位選擇.cmd](./開啟欄位選擇.cmd)，自動啟動並開啟瀏覽器；也可在專案目錄執行 `python "資料規劃/欄位選擇/server.py"`，開啟 [資料選擇網頁](http://127.0.0.1:8766/)。
- 儲存選擇會更新 [選擇結果](./資料規劃/欄位選擇/選擇結果.json)、[畫面資料規劃](./資料規劃/欄位選擇/畫面資料規劃.md)，並同步兩份中央氣象署來源說明與官方意思核對紀錄。
- 修改共用目錄後，在網頁按「更新資料說明」或執行 `python "資料規劃/中央氣象署/shared_catalog.py"`，即可重產文件。原有勾選與備註另外保存，不會隨資料說明更新被重設。
- 這是本機規劃工具；讀取官方資料的後端與天氣網站尚未因此接上或自動收集。
